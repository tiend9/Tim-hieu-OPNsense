## 1. Tổng quan về CLI của Glance

### 1.1. Hai công cụ CLI

Có hai cách tương tác với Glance từ command line:

| Công cụ                    | Lệnh                       | Trạng thái           | Khi nào dùng                   |
|----------------------------|----------------------------|----------------------|--------------------------------|
| **OpenStack Client (OSC)** | `openstack image ...`      | **Khuyên dùng**      | Tất cả môi trường hiện tại     |
| **Glance Client (legacy)** | `glance ...`               | Deprecated           | Các tính năng chưa có trong OSC|

> **Quan trọng:** Công cụ `glance` (python-glanceclient) đang trong quá trình **ngừng hỗ trợ**. Từ Dalmatian (2024.2) trở đi, `openstack image` là lựa chọn ưu tiên. Tài liệu này tập trung vào `openstack image`.

### 1.2. Cài đặt

```bash
# Cài OpenStack Client (bao gồm lệnh image)
pip install python-openstackclient

# Kiểm tra phiên bản
openstack --version

# Xem tất cả lệnh liên quan đến image
openstack image --help
```

## 2. Thiết lập môi trường

Trước khi chạy bất kỳ lệnh nào, cần xác thực với Keystone bằng một trong hai cách:

### 2.1. Dùng file openrc (khuyên dùng)

```bash
# Tạo file admin-openrc.sh
cat > admin-openrc.sh << 'EOF'
export OS_PROJECT_DOMAIN_NAME=Default
export OS_USER_DOMAIN_NAME=Default
export OS_PROJECT_NAME=admin
export OS_USERNAME=admin
export OS_PASSWORD=ADMIN_PASS
export OS_AUTH_URL=http://controller:5000/v3
export OS_IDENTITY_API_VERSION=3
export OS_IMAGE_API_VERSION=2
EOF

# Nạp biến môi trường
source admin-openrc.sh

# Kiểm tra xác thực
openstack token issue
```

### 2.2. Dùng biến môi trường trực tiếp

```bash
export OS_AUTH_URL=http://controller:5000/v3
export OS_PROJECT_NAME=admin
export OS_USERNAME=admin
export OS_PASSWORD=ADMIN_PASS
export OS_PROJECT_DOMAIN_NAME=Default
export OS_USER_DOMAIN_NAME=Default
export OS_IDENTITY_API_VERSION=3
export OS_IMAGE_API_VERSION=2
```

### 2.3. Truyền tham số trực tiếp vào lệnh

```bash
openstack --os-auth-url http://controller:5000/v3 \
          --os-project-name admin \
          --os-username admin \
          --os-password ADMIN_PASS \
          image list
```

## 3. Quản lý Image

### 3.1. Liệt kê image

```bash
# Liệt kê tất cả image mà bạn có quyền xem
openstack image list

# Liệt kê image public
openstack image list --public

# Liệt kê image private của project hiện tại
openstack image list --private

# Liệt kê image community
openstack image list --community

# Liệt kê image shared với project của bạn
openstack image list --shared

# Lọc theo tên
openstack image list --name "Ubuntu"

# Lọc theo trạng thái (active, queued, saving, killed, deleted)
openstack image list --status active

# Lọc theo định dạng
openstack image list --disk-format qcow2

# Hiển thị thêm nhiều cột thông tin
openstack image list --long

# Giới hạn số kết quả trả về
openstack image list --limit 20

# Sắp xếp kết quả
openstack image list --sort name:asc
openstack image list --sort created_at:desc
```

### 3.2. Xem thông tin chi tiết image

```bash
# Xem thông tin chi tiết (dùng tên hoặc ID)
openstack image show <tên-hoặc-ID>

# Ví dụ
openstack image show cirros-0.6.2-x86_64-disk
openstack image show abc12345-1234-1234-1234-abcdef123456

# Chỉ lấy một trường cụ thể
openstack image show cirros-0.6.2 -f value -c id
openstack image show cirros-0.6.2 -f value -c status
```

### 3.3. Tạo image mới (Upload)

```bash
# Upload file image từ local (cách phổ biến nhất)
openstack image create \
    --file /path/to/image.qcow2 \
    --disk-format qcow2 \
    --container-format bare \
    --public \
    "Ubuntu-22.04"

# Tạo image và download từ URL (web-download)
openstack image create \
    --container-format bare \
    --disk-format qcow2 \
    --public \
    --import-method web-download \
    --uri http://download.cirros-cloud.net/0.6.2/cirros-0.6.2-x86_64-disk.img \
    "cirros-0.6.2"

# Tạo image với đầy đủ tùy chọn
openstack image create \
    --file /opt/images/ubuntu-22.04-server.qcow2 \
    --disk-format qcow2 \
    --container-format bare \
    --min-disk 10 \
    --min-ram 1024 \
    --public \
    --property os_distro=ubuntu \
    --property os_version=22.04 \
    --tag ubuntu \
    --tag lts \
    "Ubuntu-22.04-LTS"
```

**Bảng các tham số quan trọng khi tạo image:**

| Tham số              | Ý nghĩa                            | Ví dụ                         |
|----------------------|------------------------------------|-------------------------------|
| `--file`             | Đường dẫn file local               | `--file /opt/ubuntu.qcow2`    |
| `--disk-format`      | Định dạng đĩa                      | `qcow2`, `raw`, `vmdk`, `iso` |
| `--container-format` | Định dạng container                | `bare` (phổ biến nhất)        |
| `--public`           | Cho phép mọi user dùng             | _(không có giá trị)_          |
| `--private`          | Chỉ project hiện tại               | _(không có giá trị)_          |
| `--shared`           | Có thể chia sẻ cho project khác    | _(không có giá trị)_          |
| `--community`        | Public nhưng ẩn khỏi list mặc định | _(không có giá trị)_          |
| `--min-disk`         | Dung lượng đĩa tối thiểu (GB)      | `--min-disk 20`               |
| `--min-ram`          | RAM tối thiểu (MB)                 | `--min-ram 2048`              |
| `--property`         | Thêm metadata tùy chỉnh            | `--property key=value`        |
| `--tag`              | Gắn tag cho image                  | `--tag production`            |
| `--protected`        | Không cho phép xóa                 | _(không có giá trị)_          |

### 3.4. Cập nhật thông tin image

```bash
# Đổi tên image
openstack image set --name "Ubuntu-22.04-LTS-v2" <image-id>

# Thay đổi visibility
openstack image set --public <image-id>
openstack image set --private <image-id>
openstack image set --shared <image-id>
openstack image set --community <image-id>

# Bảo vệ image khỏi bị xóa
openstack image set --protected <image-id>

# Bỏ bảo vệ
openstack image set --unprotected <image-id>

# Cập nhật min-disk và min-ram
openstack image set --min-disk 20 --min-ram 2048 <image-id>

# Thêm hoặc cập nhật property
openstack image set --property os_distro=ubuntu --property hw_disk_bus=virtio <image-id>

# Xóa một property
openstack image unset --property os_distro <image-id>

# Thêm tag
openstack image set --tag production --tag ubuntu <image-id>

# Xóa tag
openstack image unset --tag ubuntu <image-id>
```

### 3.5. Tải image xuống (Download)

```bash
# Tải image về file local
openstack image save --file /tmp/ubuntu-22.04.qcow2 <image-id>

# Kiểm tra file sau khi tải
ls -lh /tmp/ubuntu-22.04.qcow2
qemu-img info /tmp/ubuntu-22.04.qcow2
```

### 3.6. Xóa image

```bash
# Xóa một image
openstack image delete <image-id>

# Xóa nhiều image cùng lúc
openstack image delete <image-id-1> <image-id-2> <image-id-3>

# Xóa image bị protected => phải bỏ protected trước
openstack image set --unprotected <image-id>
openstack image delete <image-id>
```

### 3.7. Vô hiệu hóa và kích hoạt lại image (Deactivate/Reactivate)

```bash
# Vô hiệu hóa image (user không thể download hoặc dùng tạo VM)
# Chỉ admin mới làm được
openstack image deactivate <image-id>

# Kích hoạt lại image
openstack image reactivate <image-id>

# Kiểm tra trạng thái
openstack image show <image-id> -f value -c status
```

## 4. Quản lý Image Members (Chia sẻ Image)

Tính năng này cho phép chia sẻ image `--shared` với các project cụ thể khác.

### 4.1. Chia sẻ image với project khác (từ phía chủ sở hữu)

```bash
# Lấy ID của project muốn chia sẻ
openstack project show <tên-project> -f value -c id

# Thêm project vào danh sách members
openstack image add project <image-id> <project-id>
```

### 4.2. Chấp nhận / Từ chối chia sẻ (từ phía project được chia sẻ)

```bash
# Chấp nhận (image sẽ hiện trong list của project)
openstack image set --accept <image-id>

# Từ chối
openstack image set --reject <image-id>

# Để pending (mặc định khi mới được chia sẻ)
openstack image set --pending <image-id>
```

### 4.3. Xem danh sách members

```bash
# Xem tất cả project được chia sẻ image này
openstack image member list <image-id>
```

### 4.4. Xóa chia sẻ

```bash
# Chủ sở hữu xóa project khỏi danh sách members
openstack image remove project <image-id> <project-id>
```

## 5. Image Import

Import là cơ chế nâng cao hơn so với upload thông thường, cho phép xử lý image trước khi lưu.

### 5.1. Xem các phương thức import được hỗ trợ

```bash
openstack image import-info
```

### 5.2. glance-direct (Upload thủ công qua staging)

```bash
# Bước 1: Tạo image record
openstack image create \
    --disk-format qcow2 \
    --container-format bare \
    "my-image"

# Lưu lại image-id từ output
IMAGE_ID=$(openstack image show "my-image" -f value -c id)

# Bước 2: Upload file lên staging area
openstack image stage --file /path/to/image.qcow2 $IMAGE_ID

# Bước 3: Trigger import
openstack image import --import-method glance-direct $IMAGE_ID
```

### 5.3. web-download (Glance tự tải từ URL)

```bash
openstack image create \
    --disk-format qcow2 \
    --container-format bare \
    --import-method web-download \
    --uri "http://cloud.centos.org/centos/9-stream/x86_64/images/CentOS-Stream-GenericCloud-9-latest.x86_64.qcow2" \
    "CentOS-Stream-9"
```

### 5.4. copy-image (Sao chép sang store khác)

```bash
# Sao chép image sang một backend store khác
openstack image import \
    --import-method copy-image \
    --stores ceph_store \
    <image-id>
```

## 6. Quản lý Image Cache

Cache cho phép Glance lưu bản sao image tại local để tăng tốc download.

### 6.1. Xem trạng thái cache

```bash
# Xem danh sách image đang trong cache
openstack image cache list

# Kết quả gồm: image_id, hits, last_access, size
```

### 6.2. Xóa cache

```bash
# Xóa một image khỏi cache
openstack image cache delete <image-id>

# Xóa toàn bộ cache
openstack image cache delete --all
```

### 6.3. Thêm image vào hàng đợi cache (prefetch)

```bash
# Yêu cầu Glance cache trước một image (cache-prefetcher sẽ xử lý)
openstack image cache queue <image-id>
```

## 7. Metadef (Metadata Definitions - Định nghĩa Metadata)

Metadef cho phép admin định nghĩa các namespace và property chuẩn để áp dụng lên image.

### 7.1. Quản lý Namespace

```bash
# Liệt kê tất cả namespace
openstack metadef namespace list

# Xem chi tiết namespace
openstack metadef namespace show <namespace>

# Tạo namespace mới
openstack metadef namespace create \
    --public \
    --display-name "My Custom Namespace" \
    "org.example.custom"

# Xóa namespace
openstack metadef namespace delete <namespace>
```

### 7.2. Quản lý Object (bên trong namespace)

```bash
# Liệt kê objects trong namespace
openstack metadef object list <namespace>

# Xem chi tiết object
openstack metadef object show <namespace> <object-name>
```

### 7.3. Quản lý Resource Type

```bash
# Liệt kê resource types
openstack metadef resource type list

# Gán namespace vào resource type
openstack metadef namespace resource type create \
    <namespace> \
    --name OS::Glance::Image
```

## 8. Quản lý dịch vụ Glance (Admin)

### 8.1. Kiểm tra health check

```bash
# Kiểm tra trạng thái dịch vụ Glance
curl http://controller:9292/healthcheck

# Dùng openstack để liệt kê endpoints của Glance
openstack endpoint list --service image
```

### 8.2. Quản lý quota (dùng Keystone limits)

```bash
# Xem quota của một project (khi use_keystone_limits = true)
openstack quota show <project-id>

# Đặt quota image count cho project
openstack --os-cloud admin limits set \
    --project <project-id> \
    --image-count-uploading 5 \
    --image-size-total 107374182400  # 100 GB
```

### 8.3. DB migration (Admin)

```bash
# Chạy migration database lên phiên bản mới nhất
# (thường chạy sau khi upgrade Glance)
glance-manage db_sync

# Kiểm tra phiên bản schema hiện tại
glance-manage db_version

# Tạo database schema từ đầu (chỉ khi cài mới)
glance-manage db_load_metadefs
```

## 9. Các lệnh hay dùng khi Deploy OpenStack

Dưới đây là tập hợp các lệnh thường xuyên sử dụng trong thực tế triển khai OpenStack thủ công.

### 9.1. Kiểm tra Glance hoạt động sau cài đặt

```bash
# Xác thực kết nối Glance hoạt động
openstack image list

# Xem endpoint Glance đã đăng ký
openstack endpoint list --service image
openstack endpoint show <endpoint-id>
```

### 9.2. Upload image CirrOS (test nhẹ)

```bash
# Download image test CirrOS
wget http://download.cirros-cloud.net/0.6.2/cirros-0.6.2-x86_64-disk.img

# Upload lên Glance
openstack image create \
    --file cirros-0.6.2-x86_64-disk.img \
    --disk-format qcow2 \
    --container-format bare \
    --public \
    cirros-0.6.2-x86_64-disk

# Xác nhận
openstack image list
openstack image show cirros-0.6.2-x86_64-disk
```

### 9.3. Upload image Ubuntu/CentOS cho production

```bash
# Ubuntu 22.04
openstack image create \
    --file ubuntu-22.04-server-cloudimg-amd64.img \
    --disk-format qcow2 \
    --container-format bare \
    --min-disk 10 \
    --min-ram 512 \
    --public \
    --property os_distro=ubuntu \
    --property os_version=22.04 \
    --property hw_disk_bus=virtio \
    --property hw_vif_model=virtio \
    "Ubuntu-22.04-LTS"

# Rocky Linux 9
openstack image create \
    --file Rocky-9-GenericCloud.latest.x86_64.qcow2 \
    --disk-format qcow2 \
    --container-format bare \
    --min-disk 10 \
    --min-ram 512 \
    --public \
    --property os_distro=rocky \
    --property os_version=9 \
    "Rocky-Linux-9"
```

### 9.4. Script kiểm tra toàn bộ vòng đời image

```bash
#!/bin/bash
# Script kiểm tra Glance hoạt động đúng

source /etc/openstack/admin-openrc.sh

echo "=== Tạo image test ==="
openstack image create \
    --file /opt/cirros.img \
    --disk-format qcow2 \
    --container-format bare \
    --private \
    test-image-$(date +%s)

IMAGE_ID=$(openstack image list --name "test-image*" -f value -c ID | head -1)
echo "Image ID: $IMAGE_ID"

echo "=== Xem trạng thái image ==="
openstack image show $IMAGE_ID -f value -c status

echo "=== Download image ==="
openstack image save --file /tmp/test-download.img $IMAGE_ID
ls -lh /tmp/test-download.img

echo "=== Xóa image test ==="
openstack image delete $IMAGE_ID

echo "=== Hoàn thành ==="
```

### 9.5. Các lệnh xử lý nhanh thường dùng

```bash
# Lấy ID image theo tên
openstack image show "Ubuntu-22.04" -f value -c id

# Liệt kê image với format bảng gọn
openstack image list -f table -c ID -c Name -c Status -c Size

# Đếm tổng số image
openstack image list -f value -c ID | wc -l

# Xóa tất cả image ở trạng thái killed (bị lỗi)
for id in $(openstack image list --status killed -f value -c ID); do
    openstack image delete $id
done

# Copy ID tất cả image active ra file
openstack image list --status active -f value -c ID > /tmp/image-ids.txt

# Chuyển tất cả image của project sang shared
for id in $(openstack image list --private -f value -c ID); do
    openstack image set --shared $id
done

# Bảo vệ tất cả image public khỏi bị xóa
for id in $(openstack image list --public -f value -c ID); do
    openstack image set --protected $id
done
```
