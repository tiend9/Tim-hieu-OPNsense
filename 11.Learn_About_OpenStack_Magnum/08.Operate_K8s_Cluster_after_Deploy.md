# VẬN HÀNH CƠ BẢN SAU KHI DEPLOY CỤM K8S VỚI MAGNUM

## 1. Scale cụm – thêm/bớt worker node

```bash
bash  openstack coe cluster resize <cluster-name> --nodecount 5
```

## 2. Upgrade phiên bản Kubernetes

```bash
bash openstack coe cluster update <cluster-name> --kubernetes-version v1.31.2
```

## 3. Xóa cluster khi không dùng nữa

```bash
bash openstack coe cluster delete <cluster-name>
```

## 4. Rotate certificate (khi hết hạn)

```bash
bash openstack coe cluster certificate rotate <cluster-name>
```
