## II. SETUP MÔI TRƯỜNG VÀ QUY HOẠCH IP

### 1. Set up môi trường

- 3 Node là VM trên VMWare chạy ảo hoá KVM và chạy hệ điều hành Ubuntu 22.04
  - Trên Node Controller, ta sẽ cài sẵn các gói NTP, MariaDB và KeyStone, Glance, Nova và cả Horizon (DashBoard), Rabbit MQ
  - Trên Node Compute, ta cài sẵn các service nova-compute,neutron-openvswitch-agent (hoặc linuxbridge), neutron-l3-agent (DVR mode), neutron-metadata-agent
  - Trên Storage Node, ta cài Cinder và các service liên quan + cài đặt LVM

### 2 Quy hoạch IP

| Node           | Hostname      | Interface | Network              | IP Address      | Ghi chú                        |
|----------------|---------------|-----------|----------------------|-----------------|--------------------------------|
| Controller     | controller    | ens33     | External – 192.168.122.0/24 | 192.168.122.5 | Management, API endpoint, NAT ra ngoài |
|                |               | ens34     | Internal – 10.0.0.0/24     | 10.0.0.5      | Storage/Tunnel traffic         |
| Compute        | compute1      | ens33     | External – 192.168.122.0/24 | 192.168.122.6 | Management                     |
|                |               | ens34     | Internal – 10.0.0.0/24     | 10.0.0.6      | Tunnel traffic (VXLAN/GRE)     |

|                |               | ens34     | Internal – 10.0.0.0/24     | 10.0.0.7      | iSCSI Storage traffic          |

> Cinder-LVM sẽ tự quản lý thông qua Volume Group `cinder-volumes`.
