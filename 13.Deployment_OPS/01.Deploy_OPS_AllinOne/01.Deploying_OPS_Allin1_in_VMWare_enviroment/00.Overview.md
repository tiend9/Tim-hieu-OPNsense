# OVERVIEW

## 1. Mô hình OpenStack All-in-One trên VMware

VMware chỉ đóng vai trò hypervisor chạy VM, còn OpenStack chạy bên trong 1 VM.

```text
VMware Workstation / ESXi
        │
        └── VM: OpenStack Controller + Compute (All in One)
                OS: Ubuntu / CentOS / Rocky
                Services:
                - Keystone
                - Glance
                - Nova
                - Neutron
                - Cinder
                - Horizon
```

Tức là:

```text
VMware → 1 VM Linux → cài OpenStack full
```

## 2. Cấu hình VM khuyến nghị

Để OpenStack chạy ổn:

| Resource | Khuyến nghị      |
| -------- | ---------------- |
| CPU      | 4 vCPU           |
| RAM      | 8 GB (tối thiểu) |
| Disk     | 80 GB            |
| Network  | 2 NIC            |

## 3. Cấu hình Network trong VMware

Nên tạo 2 network adapter cho VM.

### NIC1 – Management network

```text
VMnet8 (NAT) hoặc Bridged
```

Ví dụ:

`192.168.70.100`

Dùng cho:

- SSH
- API
- Dashboard

### NIC2 – Provider Network (VM network)

```text
VMnet2 / Host-only
```

Ví dụ:

`10.0.0.0`/24

Dùng cho:

- VM của OpenStack ra mạng

## 4. OS nên dùng

Khuyên dùng:

- Ubuntu Server 22.04

Vì:

- support OpenStack tốt
- devstack / microstack dễ

## 5. Cách deploy OpenStack All in One (3 cách)

### `Cách 1` – DevStack (dễ nhất để học)

Phù hợp:

- lab
- demo
- học OpenStack

### `Cách 2` – Packstack (RHEL / Rocky)

Phù hợp nếu dùng:

- Rocky
- CentOS

### `Cách 3` – MicroStack (nhanh nhất)

Cài trên Ubuntu:

```bash
sudo snap install microstack --classic
```

Init:

```bash
sudo microstack init --auto
```

## 8. VM bên trong OpenStack chạy như nào?

OpenStack dùng KVM làm hypervisor.

Mô hình thật sẽ là:

```text
VMware
   │
   └── VM Ubuntu (OpenStack)
           │
           └── KVM
                │
                └── OpenStack VM
```

=> Tức là nested virtualization.

## 9. Quan trọng: phải bật Nested Virtualization

Trong VMware:

VM Settings:

```text
→ CPU
→ Enable: Virtualize Intel VT-x/EPT
```

Nếu không bật:

- Nova compute không tạo được VM
