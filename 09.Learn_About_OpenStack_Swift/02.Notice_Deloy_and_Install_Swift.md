# LƯU Ý KHI VẬN HÀNH VÀ TRIỂN KHAI SWIFT TRÊN OPENSTACK

> **Phiên bản tham chiếu**: OpenStack **2026.1 Gazpacho** + Kolla-Ansible **19.x**

## I. YÊU CẦU HẠ TẦNG

### 1. Số node tối thiểu

| Mô hình        | Số node      | Mô tả                                                      |
|----------------|--------------|------------------------------------------------------------|
| **Lab/Dev**    | 1 node       | All-in-one: Proxy + Storage cùng node, replica=1           |
| **Minimal**    | 3 node       | Proxy riêng + 2 Storage node, replica=2 (không khuyến nghị)|
| **Production** | 4+ node      | 1-2 Proxy Node + 3+ Storage Node, replica=3                |
| **HA**         | 6+ node      | 2+ Proxy (behind LB) + 4+ Storage (2 zone mỗi zone 2 node) |

> **Quy tắc**: Số Storage Node ≥ `replica_count` × `zone_count`. Production tối thiểu **3 zone, 3 node** (1 node/zone).

### 2. Disk layout — XFS bắt buộc

Swift yêu cầu **XFS filesystem** với mount options cụ thể để hoạt động đúng:

```bash
# Trên MỖI Storage Node — format và mount disk:
# Giả sử disk data: /dev/sdb, /dev/sdc

# Format XFS:
mkfs.xfs -f /dev/sdb
mkfs.xfs -f /dev/sdc

# Tạo mount point:
mkdir -p /srv/node/sdb
mkdir -p /srv/node/sdc

# Thêm vào /etc/fstab (mount persistent):
echo "/dev/sdb /srv/node/sdb xfs noatime,nodiratime,nobarrier,logbufs=8 0 2" >> /etc/fstab
echo "/dev/sdc /srv/node/sdc xfs noatime,nodiratime,nobarrier,logbufs=8 0 2" >> /etc/fstab

# Mount ngay:
mount -a

# Phân quyền:
chown -R swift:swift /srv/node/
```

**Giải thích mount options**:

| Option        | Ý nghĩa                                            |
|---------------|----------------------------------------------------|
| `noatime`     | Không ghi access time → giảm write I/O             |
| `nodiratime`  | Không ghi directory access time                    |
| `nobarrier`   | Tắt write barrier (nếu dùng RAID với BBU)          |
| `logbufs=8`   | Tăng XFS log buffer → giảm write stall             |

> **Không dùng ext4 hay btrfs** — Swift dùng xattr mở rộng (`user.swift.metadata`) chỉ hoạt động tốt với XFS.

### 3. Network — Tách Storage Network

```text
Proxy Node:
  eth0 (Management): 10.0.0.0/24       → Keystone, Nova, Glance
  eth1 (Public API):  192.168.1.0/24   → Client truy cập Swift endpoint

Storage Node:
  eth0 (Management): 10.0.0.0/24       → Quản lý, SSH
  eth1 (Storage):    172.16.0.0/24     → Replication giữa storage node
                                         Proxy → Object/Account/Container
```

**Cấu hình `/etc/swift/object-server.conf` trỏ vào Storage Network**:

```ini
[DEFAULT]
bind_ip = 172.16.0.x     # IP của Storage Network, không phải Management
bind_port = 6200
```

### 2. Gán label cho Swift storage disk

Kolla-Ansible nhận biết disk Swift qua **filesystem label** `KOLLA_SWIFT_DATA`:

```bash
# Trên MỖI Storage Node — gán label cho disk XFS:
sudo mkfs.xfs -f -L "KOLLA_SWIFT_DATA" /dev/sdb
sudo mkfs.xfs -f -L "KOLLA_SWIFT_DATA" /dev/sdc

# Nếu disk đã format, chỉ đổi label:
sudo xfs_admin -L "KOLLA_SWIFT_DATA" /dev/sdb

# Verify label:
blkid /dev/sdb
# /dev/sdb: LABEL="KOLLA_SWIFT_DATA" TYPE="xfs"
```

## III. TẠO RING — BƯỚC KHÔNG ĐƯỢC SAI

### 1. Thứ tự tạo Ring (deploy thủ công)

```text
Bước 1: Tạo builder file (định nghĩa ring cơ bản)
Bước 2: Add device vào ring (gán storage node/disk)
Bước 3: Rebalance ring (phân phối partition vào device)
Bước 4: Phân phối ring.gz file sang TẤT CẢ node
Bước 5: Khởi động dịch vụ Swift
```

> **Không được** bỏ qua bước rebalance hoặc distribute. Ring không đồng bộ sẽ gây 500 error khi request.

### 2. Tạo 3 Ring builder file

```bash
# Tham số: partition_power=10 → 2^10=1024 partitions
#           replicas=3
#           min_part_hours=1 (tối thiểu 1 giờ giữa 2 lần rebalance cùng partition)

swift-ring-builder /etc/swift/object.builder    create 10 3 1
swift-ring-builder /etc/swift/container.builder create 10 3 1
swift-ring-builder /etc/swift/account.builder   create 10 3 1

# Kiểm tra file builder đã tạo:
ls -lh /etc/swift/*.builder
```

**Chọn partition_power phù hợp**:

| Cluster size     | Partition power | Tổng partitions |
|------------------|-----------------|-----------------|
| Lab (1-3 node)   | 8               | 256             |
| Small (4-10 node)| 10              | 1024            |
| Medium (10-50)   | 12              | 4096            |
| Large (50+)      | 14              | 16384           |

> **Quy tắc**: `100 × replica_count × max_drives / partitions ≈ 100` (số partition per drive lý tưởng là ~100).

### 3. Add device vào từng Ring

```bash
# Format lệnh:
# swift-ring-builder <builder> add \
#   --region <R> --zone <Z> \
#   --ip <storage-net-ip> --port <port> \
#   --replication-ip <rep-ip> --replication-port <rep-port> \
#   --device <diskname> --weight <weight>

# ===== Object Ring =====

swift-ring-builder /etc/swift/object.builder add \
  --region 1 --zone 1 \
  --ip 172.16.0.21 --port 6200 \
```

### 4. Rebalance Ring

```bash
# Rebalance cả 3 ring:
swift-ring-builder /etc/swift/object.builder    rebalance
swift-ring-builder /etc/swift/container.builder rebalance
swift-ring-builder /etc/swift/account.builder   rebalance

# Verify balance (lý tưởng gần 0.00):
swift-ring-builder /etc/swift/object.builder
# object.builder, build version 6
# 1024 partitions, 3.000000 replicas, 1 regions, 3 zones, 6 devices, 0.00 balance
```

### 5. Phân phối Ring file sang tất cả node

```bash
# Sau rebalance, 3 file .ring.gz được tạo:
ls /etc/swift/*.ring.gz
# /etc/swift/account.ring.gz
# /etc/swift/container.ring.gz
# /etc/swift/object.ring.gz

# Copy đến TẤT CẢ node (Proxy + Storage):
for NODE in 10.0.0.11 172.16.0.21 172.16.0.22 172.16.0.23; do
  scp /etc/swift/*.ring.gz root@${NODE}:/etc/swift/
  echo "Copied to $NODE"
done

# Verify trên storage node:
ssh root@172.16.0.21 "ls -lh /etc/swift/*.ring.gz"
```

> **Mỗi khi rebalance ring**, phải copy lại ring file mới sang **tất cả node**. Node nào có ring cũ sẽ route request sai.

### 6. Các lỗi phổ biến sau deploy

| Lỗi                                         | Nguyên nhân                                        | Cách fix                                         |
|---------------------------------------------|----------------------------------------------------|--------------------------------------------------|
| `401 Unauthorized`                          | Sai password Swift trong authtoken                 | Kiểm tra `password` trong `proxy-server.conf`    |
| `503 Service Unavailable`                   | Proxy không reach được storage node                | Check firewall, storage network, port 6200-6202  |
| `404 Not Found` (container tồn tại)         | Ring file không đồng bộ giữa các node              | Redistribute ring file, restart service          |
| `507 Insufficient Storage`                  | Disk storage đầy hoặc chưa mount                   | Kiểm tra `df -h /srv/node/`, `mount \| grep srv` |
| Object upload thành công nhưng download lỗi | `swift_hash_path_*` khác nhau giữa node            | Copy swift.conf đồng nhất, restart tất cả service|
| Replication không chạy                      | Firewall chặn replication port                     | Mở port 6200-6202 trên storage network           |
