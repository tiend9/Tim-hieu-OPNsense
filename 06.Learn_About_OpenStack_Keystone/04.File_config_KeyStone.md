# TÌM HIỂU FILE CẤU HÌNH KEYSTONE

Tài liệu này tập trung vào việc giải mã file cấu hình chính của Keystone và các thành phần liên quan.

---

## 1. Vị trí các file cấu hình (Where are they?)

Trong các hệ thống Linux (Ubuntu/CentOS), các file cấu hình của Keystone mặc định nằm tại thư mục: `/etc/keystone/`

| File | Chức năng |
| :--- | :--- |
| **`keystone.conf`** | **File cấu hình chính**. Chứa mọi thiết lập về DB, Token, Drivers, Logging... |
| `keystone-paste.ini` | Cấu hình cho WSGI pipeline (cách xử lý request HTTP). |
| `policy.yaml` (hoặc `.json`) | Định nghĩa các quy tắc phân quyền (RBAC) chi tiết. |
| `logging.conf` | Cấu hình chi tiết về cách ghi log (nếu không cấu hình trực tiếp trong file chính). |
| `default_catalog.templates` | (Tùy chọn) Template cho Service Catalog nếu dùng backend file. |

---

## 2. Cấu trúc file `keystone.conf`

File này sử dụng định dạng **INI**, chia thành các khối gọi là **Sections** nằm trong dấu ngoặc vuông `[]`.

### 2.1 Section `[DEFAULT]`
Chứa các thiết lập chung toàn hệ thống.
- `admin_token`: (Đã cũ) Token quản trị tạm thời khi chưa bootstrap xong.
- `log_dir`: Thư mục lưu log (thường là `/var/log/keystone`).
- `debug`: Bật/Tắt chế độ debug (True/False).

### 2.2 Section `[database]`
Cấu hình kết nối tới cơ sở dữ liệu (MySQL/PostgreSQL).
- `connection`: Chuỗi kết nối.
  *Ví dụ:* `connection = mysql+pymysql://keystone:KEYSTONE_DBPASS@controller/keystone`

### 2.3 Section `[token]`
Cấu hình về vòng đời và loại Token.
- `provider`: Loại token sử dụng. Hiện nay mặc định là `fernet`.
- `expiration`: Thời gian sống của token (giây). Mặc định là `3600` (1 giờ).

### 2.4 Section `[identity]`
Cấu hình Driver quản lý danh tính (User, Group).
- `driver`: Thường dùng `sql` (lưu trong DB) hoặc `ldap` (nếu tích hợp AD/LDAP).

### 2.5 Section `[assignment]`
Cấu hình Driver quản lý việc gán quyền (Role Assignment).
- `driver`: Mặc định là `sql`.

### 2.6 Section `[resource]`
Quản lý Project và Domain.
- `driver`: Mặc định là `sql`.

### 2.7 Section `[fernet_tokens]`
Cấu hình cho loại token Fernet.
- `key_repository`: Thư mục chứa các khóa mã hóa (thường là `/etc/keystone/fernet-keys/`).
- `max_active_keys`: Số lượng key tối đa được duy trì khi rotate.

## 3. Các Option quan trọng cần lưu ý (Detailed Options)

Dưới đây là các thông số mày sẽ thường xuyên phải chỉnh sửa khi cài đặt hoặc tối ưu:

| Option | Section | Giải thích |
| :--- | :--- | :--- |
| **`connection`** | `[database]` | Địa chỉ DB. Sai cái này Keystone không thể khởi động. |
| **`provider`** | `[token]` | Chọn `fernet` (mặc định), `uuid` (cũ), hoặc `pki` (rất cũ). |
| **`driver`** | `[identity]` | Nếu muốn dùng LDAP, mày phải sửa driver này thành `ldap`. |
| **`max_token_size`** | `[DEFAULT]` | Giới hạn kích thước token để tránh lỗi buffer. |
| **`caching`** | `[cache]` | Bật cache (thường dùng Memcached) để tăng tốc độ validate token. |
| **`public_endpoint`** | `[DEFAULT]` | URL public của Keystone để các service khác biết đường gọi. |

## 4. Module WSGI & Pipeline (`keystone-paste.ini`)

Keystone chạy dưới dạng một ứng dụng Python WSGI. File `keystone-paste.ini` định nghĩa các "lớp lọc" (middleware) mà một request phải đi qua trước khi tới lõi xử lý.

- **`pipeline:public_api`**: Quy định các middleware cho người dùng thông thường.
- **`pipeline:admin_api`**: Quy định cho các yêu cầu quản trị.

> **Lưu ý:** Thường mày không cần sửa file này trừ khi muốn cài thêm các module bảo mật hoặc audit đặc biệt.

---

## 5. Phân quyền API với `policy.yaml`

Đây là nơi mày định nghĩa "Ai được làm gì". 
- Định dạng: `"quy_tắc": "điều_kiện"`
- *Ví dụ:* `"identity:create_user": "role:admin"` 
  *(Nghĩa là: Chỉ những người có role admin mới được tạo user)*

Từ các phiên bản mới (Victoria, Wallaby...), OpenStack chuyển dần sang **Secure RBAC** với các khái niệm `system-scoped`, `domain-scoped` và `project-scoped` rất mạnh mẽ.

---

## 6. Mẹo kiểm tra cấu hình

Sau khi sửa file `.conf`, mày có thể dùng lệnh sau để kiểm tra xem có lỗi cú pháp không hoặc xem giá trị hiện tại:

```bash
# Xem toàn bộ cấu hình hiện tại (kể cả các giá trị mặc định)
keystone-manage config_list

# Kiểm tra trạng thái kết nối DB
keystone-manage db_version
```

**Quan trọng:** Sau mỗi lần sửa file cấu hình, mày **PHẢI** restart dịch vụ để áp dụng:
```bash
# Nếu chạy qua Apache (phổ biến nhất)
sudo systemctl restart apache2
```
